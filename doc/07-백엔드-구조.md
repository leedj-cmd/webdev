# 백엔드 구조

## 개요

백엔드는 `fastapi-vue-board/backend`에 있으며 FastAPI 기반 비동기 API 서버입니다.

## 주요 파일

```text
backend/
├── main.py
├── pyproject.toml
├── requirements.txt
├── create_tables.py
├── seed_opportunities.py
├── test_db_sync.py
└── app/
    ├── core/
    │   ├── config.py
    │   └── security.py
    ├── database.py
    ├── dependencies.py
    ├── models/
    ├── routers/
    ├── schemas/
    └── services/
```

## DB 계층

`app/database.py`:

- `create_async_engine(settings.DATABASE_URL, echo=True)`
- `AsyncSessionLocal`
- `Base`
- `get_db()`
- `init_db()`

주의:

- `echo=True`는 운영에서 SQL 로그 노출과 성능 부담이 있습니다.
- `init_db()`는 `create_all()`을 호출하고, `scraps` 테이블 누락 컬럼을 직접 `ALTER TABLE`로 보정합니다.

## 인증/보안

`app/core/security.py`:

- bcrypt password hash/verify
- bcrypt 72 bytes 제한 대응
- JWT access/refresh token 생성
- JWT decode
- 비밀번호 reset token 생성 및 SHA-256 hash

`app/dependencies.py`:

- `HTTPBearer` 기반 `get_current_user`
- 선택 인증용 `get_optional_current_user`

주의:

- `app/routers/auth.py` 내부에도 별도 `get_current_user`가 정의되어 있습니다. 중복 구현으로 토큰 타입 검증 방식이 달라질 수 있으므로 통합이 필요합니다.

## 서비스 계층

### AIService

`app/services/ai_service.py`:

- Singleton 형태
- Provider 우선순위: Groq → OpenAI → Gemini
- FAQ 답변 생성
- 금칙어 기반 1차 검열
- Transformers text-classification 기반 2차 검열

### external_opportunities

`app/services/external_opportunities.py`:

- 외부 채용/공모전 데이터를 수집하고 내부 응답 형태로 매핑
- 15분 TTL 메모리 캐시
- HTTP timeout 4초
- 외부 API 실패 시 빈 목록 반환

외부 출처:

- Worknet
- Saramin
- Kontests
- Codeforces
- ContestKorea
- KIPRIS

## 개선 권장

- 라우터에 몰린 비즈니스 로직을 service/repository 계층으로 점진 분리합니다.
- 인증 의존성을 `app/dependencies.py` 하나로 통합합니다.
- 관리자 권한 확인 `require_admin()` 중복을 공통 dependency로 분리합니다.
- WebSocket 메시지는 문자열 대신 JSON schema로 통일합니다.
- 마이그레이션은 Alembic으로 전환합니다.
- 운영용 설정에서 SQLAlchemy `echo=False`를 기본값으로 둡니다.

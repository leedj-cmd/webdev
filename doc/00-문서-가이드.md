## 표기 규칙

- `현재 구현`: 코드에서 확인된 동작입니다.
- `주의`: 운영 또는 유지보수 시 리스크가 있는 부분입니다.
- `개선 권장`: 반드시 즉시 고쳐야 하는 것은 아니지만 다음 작업에서 우선 검토할 항목입니다.
- API 경로는 백엔드 기준 URL path만 표기합니다. 로컬 기본 주소는 `http://127.0.0.1:8000`입니다.

# 프론트엔드 구조

## 개요

프론트엔드는 `fastapi-vue-board/frontend`에 있으며 Vue 3, Vite, Vue Router, Pinia, Axios를 사용합니다.

## 주요 파일

```text
frontend/
├── package.json
├── vite.config.js
└── src/
    ├── main.ts
    ├── App.vue
    ├── router/index.js
    ├── api/
    │   ├── axios.js
    │   └── NotificationApi.js
    ├── stores/
    │   ├── auth.js
    │   └── NotificationStore.js
    ├── components/
    │   ├── Navbar.vue
    │   ├── ChatWidget.vue
    │   └── CensorshipModal.vue
    └── views/
```

## 앱 초기화

`src/main.ts`:

- `assets/main.css` 로드

`src/App.vue`:

- 전역 배경/레이아웃
- `Navbar`
- `RouterView`

## 라우팅

`src/router/index.js`에서 라우트를 정의합니다.

| Path | View | 권한 |
|---|---|---|
| `/` | `HomeView` | 공개 |
| `/jobs` | `JobListView` | 공개 |
| `/contests` | `ContestListView` | 공개 |
| `/posts` | `PostView` | 공개 |
| `/posts/create` | `PostCreateView` | 로그인 |
| `/posts/:id` | `PostDetailView` | 공개 |
| `/community` | `CommunityView` | 공개 |
| `/faq` | `AiChatView` | 공개 |
| `/login` | `LoginView` | 게스트 |
| `/register` | `RegisterView` | 게스트 |
| `/profile` | `ProfileView` | 로그인 |
| `/chat` | `ChatView` | 로그인 |
| `/admin` | `AdminView` | 관리자 |
| `/jobs/create`, `/jobs/:id/edit` | `JobFormView` | 관리자 |
| `/contests/create`, `/contests/:id/edit` | `ContestFormView` | 관리자 |

라우터 guard:

- `guestOnly`: 로그인 사용자는 home으로 이동
- `requiresAuth`: 미로그인 사용자는 login으로 이동
- `requiresAdmin`: 관리자가 아니면 home으로 이동

## 상태 관리

### auth store

`src/stores/auth.js`:

- `user`
- `token`
- `isLoggedIn`
- `isAdmin`
- `fetchMe()`
- `register()`
- `adminRegister()`
- `promoteToAdmin()`
- `login()`
- `logout()`

Access Token은 `localStorage.access_token`에 저장합니다.

### notification store

`src/stores/NotificationStore.js`:

- `notifications`
- `loading`
- `wsConnected`
- `unreadCount`
- `hasUnread`
- `fetchNotifications()`
- `markAsRead()`
- `markAllAsRead()`
- `connectWs(token)`
- `disconnectWs()`

주의:

- WebSocket URL을 `location.host` 기준으로 생성합니다. 프론트 개발 서버가 `localhost:5173`이면 백엔드 `/notifications/ws`가 아니라 프론트 서버로 연결될 수 있습니다.

## API 클라이언트

`src/api/axios.js`:

- baseURL: `http://127.0.0.1:8000`
- JSON 기본 header
- 요청 interceptor에서 `localStorage.access_token`을 Bearer token으로 첨부
- 401 응답 시 token 삭제 후 `/login` 이동

주의:

- 일부 화면은 공통 `api` 인스턴스 대신 raw `axios`와 하드코딩 URL을 사용합니다.
- `NotificationApi.js`도 raw `axios`를 사용하므로 baseURL과 Authorization header가 누락될 수 있습니다.

## 구현 스타일

현재 Composition API와 Options API가 혼재합니다.

- Composition API: `HomeView`, `LoginView`, `RegisterView`, `ProfileView`, `ChatView`, `JobFormView`, `ContestFormView`
- Options API: `PostView`, `PostCreateView`, `PostDetailView`, `JobListView`, `ContestListView`

개선 권장:

- 신규 화면은 Composition API로 통일합니다.
- API 호출은 반드시 `src/api/axios.js`의 `api` 인스턴스를 사용합니다.
- WebSocket URL 생성은 환경 변수 또는 API base URL에서 파생하도록 통일합니다.
- `Community.vue`와 `CommunityView.vue` 중 실제 사용 화면 기준으로 중복을 정리합니다.

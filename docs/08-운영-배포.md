# 운영 배포

## 로컬 실행 구성

### PostgreSQL

`fastapi-vue-board/docker-compose.yml`:

```yaml
services:
  db:
    image: postgres:latest
    container_name: postgres-task
    restart: always
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: "1234"
      POSTGRES_DB: project
    ports:
      - "5432:5432"
    volumes:
      - ./postgres_data:/var/lib/postgresql
```

실행:

```bash
cd fastapi-vue-board
docker compose up -d
```

주의:

- 운영에서는 `postgres:latest` 대신 고정 버전을 사용합니다.
- 운영 비밀번호는 절대 저장소에 두지 않습니다.
- 볼륨 경로는 PostgreSQL 공식 이미지 기준으로 `/var/lib/postgresql/data` 사용을 검토합니다.

### 백엔드

예상 실행:

```bash
cd fastapi-vue-board/backend
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

필수 환경 변수:

```env
DATABASE_URL=postgresql+asyncpg://postgres:1234@127.0.0.1:5432/project
SECRET_KEY=replace-with-secure-random-string
```

선택 환경 변수:

```env
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
REFRESH_TOKEN_EXPIRE_DAYS=7
ADMIN_SECRET=replace-with-admin-secret
GROQ_API_KEY=
OPENAI_API_KEY=
GEMINI_API_KEY=
GEMINI_KEY=
WORKNET_API_KEY=
KIPRIS_API_KEY=
# 이메일 인증 / 비밀번호 재설정 메일 (SMTP)
FRONTEND_URL=http://localhost:5173
EMAIL_FROM=no-reply@example.com
EMAIL_FROM_NAME=TechBridge
SMTP_HOST=
SMTP_PORT=587
SMTP_USERNAME=
SMTP_PASSWORD=
SMTP_USE_TLS=true
SMTP_USE_SSL=false
```

이메일 인증 SMTP 설정 상세는 `fastapi-vue-board/docs/email-verification.md`를 참고합니다.

### 프론트엔드

```bash
cd fastapi-vue-board/frontend
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
```

## 배포 전 점검

### 보안

- `SECRET_KEY`를 강한 랜덤 문자열로 교체
- `ADMIN_SECRET` 기본값 제거
- `.env`가 저장소에 포함되지 않도록 확인
- 운영 SMTP 계정/키를 안전하게 보관하고 발신자 도메인 인증 적용
- CORS origin을 운영 도메인으로 제한
- 프로필 이미지 업로드 파일 확장자, MIME type, 크기 제한 추가
- 인증 토큰을 query parameter로 전달하는 코드 제거

### DB

- Alembic 마이그레이션 도입
- `create_all()` 운영 자동 실행 여부 재검토
- `create_tables.py`의 drop all 스크립트 운영 접근 차단
- 인덱스/유니크 제약 추가 검토
- 정기 백업 정책 수립

### 백엔드

- SQLAlchemy `echo=True` 비활성화
- 외부 API timeout, retry, rate limit 정책 확정
- AI 모델 로딩 실패 시 API degrade 정책 확정
- WebSocket 연결 수/메모리 관리 정책 검토
- structured logging 도입

### 프론트엔드

- API base URL을 환경 변수로 분리
- raw axios 사용 제거
- WebSocket URL을 백엔드 origin 기준으로 생성
- `localStorage` token 보관 리스크 검토
- 관리자 화면 접근은 프론트 guard뿐 아니라 백엔드 권한 검사로 유지

## 권장 운영 아키텍처

```text
Client
  → HTTPS
  → Reverse Proxy / Load Balancer
  → Static frontend hosting or Nginx
  → FastAPI app server
  → PostgreSQL managed DB
```

WebSocket 사용 시 reverse proxy에서 다음 설정이 필요합니다.

- `Upgrade` header 전달
- `Connection: upgrade`
- idle timeout 조정
- sticky session 또는 외부 pub/sub 도입 검토

## 배포 산출물

| 영역 | 산출물 |
|---|---|
| 프론트엔드 | Vite build 결과물 `dist/` |
| 백엔드 | Python app, dependency lock, 환경 변수 |
| DB | PostgreSQL schema migration |
| 파일 업로드 | `/uploads` 영속 저장소 |
| 로그 | API 로그, 에러 로그, access 로그 |

## 모니터링 항목

- 외부 API 실패율

## 롤백 전략

- 프론트엔드: 이전 정적 빌드로 교체
- 백엔드: 이전 이미지/릴리스로 재배포
- DB: migration down script와 백업 복구 절차 필요
- 파일 업로드: DB와 파일 저장소 간 참조 불일치 점검 필요

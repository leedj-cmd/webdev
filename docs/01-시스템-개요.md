# 시스템 개요

## 한 줄 요약

이 프로젝트는 취업 준비생과 IT 개발자를 대상으로 게시판, 채용 공고, 공모전, 커뮤니티, 채팅, 알림, AI FAQ를 제공하는 커리어 커뮤니티 웹 애플리케이션입니다.

## 기술 스택

| 영역 | 기술 |
|---|---|
| 프론트엔드 | Vue 3, Vite, Vue Router, Pinia, Axios |
| 백엔드 | FastAPI, SQLAlchemy Async, Pydantic, python-jose, bcrypt |
| DB | PostgreSQL, asyncpg |
| 실시간 | WebSocket: 채팅, 알림 |
| AI | Groq/OpenAI/Gemini 중 환경 변수 기반 우선 선택, Transformers 기반 욕설/공격성 검열 |
| 외부 데이터 | Worknet, Saramin, Kontests, Codeforces, ContestKorea, KIPRIS |
| 로컬 인프라 | Docker Compose로 PostgreSQL 실행 |

## 런타임 구성

브라우저는 Vue 앱에 접근하고, Vue 앱은 Axios를 통해 FastAPI 서버에 요청합니다. FastAPI는 PostgreSQL에 데이터를 저장하고, 채팅/알림 기능은 WebSocket으로 별도 연결을 유지합니다.

```text
Browser
  │
  ▼
Vue/Vite frontend :5173
  │ REST / WebSocket
  ▼
FastAPI backend :8000
  │ SQLAlchemy async
  ▼
PostgreSQL :5432
```

## 백엔드 진입점

현재 핵심 진입점은 `fastapi-vue-board/backend/main.py`입니다.

- 앱 이름: `DevCareer API`
- CORS 허용 origin: `http://localhost:5173`, `http://127.0.0.1:5173`
- 서버 시작 시 `init_db()` 실행
- 서버 시작 시 AI 검열 모델을 백그라운드 로드
- `/uploads` 정적 파일 마운트
- 라우터 등록: auth, post, comment, interaction, job, contest, scrap, admin, chat, notification, report, community, faq

주의: 루트의 `backend/main.py`는 라우터 일부만 포함하고 `/` 경로가 중복 정의되어 있습니다. 현재 앱 본체와 혼동되지 않도록 정리 대상입니다.

## 현재 아키텍처 특성

- 백엔드는 도메인별 라우터 중심 구조입니다.
- 서비스 계층은 `ai_service.py`, `external_opportunities.py` 정도로 제한적이며, 대부분 비즈니스 로직은 라우터에 있습니다.
- 데이터베이스 마이그레이션 도구는 없고, 앱 시작 시 `Base.metadata.create_all()`을 호출합니다.
- 일부 스키마와 모델은 SQLAlchemy 2.0 typed mapping과 기존 `Column` 스타일이 혼재합니다.
- 프론트엔드는 Composition API와 Options API가 섞여 있습니다.
